## Key vocabulary (in your own words)
git status
- repository: a project that needs to be done
- commit: check the history of the changes you have made 
- branch: i can work on something without changing the main project
- push / pull: push - uploads my changes to GitHub pull - gets changes from a remote repository
- pull request: request to merge or combine changes from one branch into another
- merge conflict: happens when two branches change the same  part of a project or file and git doesn't know which one to keep or to apply the changes to.
